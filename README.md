# Daily Health Tracker App

## Overview
The **Daily Health Tracker** is a Flutter mobile application that helps users track their daily health habits. Users can log activities such as water intake, exercise, sleep, and meals, and visualize their progress over time. The app provides an intuitive interface with easy navigation and clean UI design, making health tracking simple and engaging.

### Key Features
- Log daily activities (exercise, water, sleep, meals)
- View daily, weekly, and monthly progress
- Simple and clean UI using Flutter
- Responsive and fast performance
- Notifications for reminders (optional)
- Uses GetX for state management
